# 猫语匣技术支持

猫语匣支持 iOS 17 及以上。界面跟随系统语言；没有对应语言时显示英语。

## 常见情况

- **没有提醒：** 打开系统设置中的猫语匣通知，并在应用里打开对应提醒。提醒是本地通知，需要允许通知权限。
- **换了手机资料没过来：** 两台设备使用同一个 Apple ID，并打开 iCloud。同步可能要等一会儿，打开应用后会再拉取一次。
- **小组件是空的：** 先打开一次猫语匣，再回到主屏幕刷新小组件。小组件只读这台手机里的摘要。
- **名字显示成「我家猫」：** 首次引导如果没填名字，会使用这个默认称呼，之后可在猫档案里修改。
- **翻译不像真翻译：** 人话转猫语是按关键词匹配后播放猫叫，只供娱乐，不会联网识别。
- **驱虫和疫苗：** 只按你填写的日期估算提醒，不能代替兽医。

## 联系

描述机型、iOS 版本和具体现象，发邮件至：[1175903571@qq.com](mailto:1175903571@qq.com)。我们没有应用内账号，卸载即可清除本机数据。

# CatSpeak Support

CatSpeak requires iOS 17 or later. The interface follows the system language. If that language is not supported, the app uses English.

## Common questions

- **No reminders:** Allow notifications for CatSpeak in Settings, then turn on the reminder inside the app. Reminders are local and need notification permission.
- **Data did not appear on a new phone:** Use the same Apple ID on both devices and turn on iCloud. Sync can take a while. Open the app again so it can pull the latest values.
- **The widget is empty:** Open CatSpeak once, then refresh the widget on the Home Screen. The widget only reads the summary stored on that phone.
- **The name shows as “My Cat”:** If you leave the name blank during setup, the app uses that default. You can change it later in the cat profile.
- **Translation does not look like a real translation:** Human-to-cat lines match keywords and then play a cat sound. This is for fun and does not use an online translator.
- **Deworming and vaccines:** Dates only estimate a reminder from what you entered. They do not replace a veterinarian.

## Contact

Email your device model, iOS version, and what happened to [1175903571@qq.com](mailto:1175903571@qq.com). There is no in-app account. Deleting the app clears the data stored on that device.
